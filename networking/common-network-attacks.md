# Common Network Attacks

1. Common Network Intrusion Attack are: Malware, Spoofing, Packet Sniffing, Packet Flooding.

2. Denial of Service attack(DoS) - An attack that targets a network or server by flooding with network traffic.
2. Distributed Denial of Service Attack(DDoS) - A type of denial of service attack that uses multiple devices or servers in different locations to flood the target network with unwanted traffic.
3. SYN(Synchronize) Flood Attack - A type of DoS attack that simulate a TCP connection and flood a server with syn packets.
4. Internet Control Message Protocol(ICMP) - An internet protocol used by devices to tell each other about data transmission errors across the network.
ICMP Flood Attack - A type of DoS attack performed by an attacker repeatedly sending ICMP packets to a network server.
5. Ping of Death - A type of DoS attack caused when a hacker pings a system by sending it an oversized ICMP packet that is bigger than 64KB.
6. Passive Packet Sniffing - A type of attack where data packets are read in transit.
7. Active Packet Sniffing - A type of attack where data packets are manipulated in transit.
IP Spoofing - A type of attack performed when an attacker change the IP of a data packet to impersonate an authorized system and gain access to a network.
