# FIREWALLS

1. Firewall - A network security device that monitors traffic to and from your network.
2. Port Filtering - A firewall function that blocks or allows certain port numbers to limit unwanted communication.
3. Firewalls type: Physical and Software firewall.
4. Cloud-Based Firewall - Software firewalls that are hosted by the cloud service providers.
5. Firewall can be Stateless or Stateful
6. Stateful Firewall - A class of firewall that keeps track of information passing through it and proactively filters out threats.
7. Stateless Firewall - A class of firewall that operates based on a predefined rules and does not keep track of information from data packets.
Stateful is more secured that stateless.
8. Benefit of next generation firewalls(NGFWS) 
- Deep packet inspection
- Intrusion protection
- Threat intelligence
