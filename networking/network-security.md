# NETWORK
1. Network is a group of connected devices, and can communicate together.
2. Network types are LAN and WAN.

# NETWORK DEVICES

1. HUB - A network device that broadcasts information to every devices on the network.
2. SWITCH - A network device that make connections between a specific device on a network by sending and receiving data between them. It is smarter than hub, and passes information to the intended location.
3. ROUTER - A network device that connects multiple networks together.
4. MODERM - A device that connects router to the internet and provide internet access to the LAN.

# Virtualization tools is a piece of software that performs network operations. They carry out those functions of switch, hub, router, moderm.

# CLOUD
1. Cloud Computing is the practice of using remote server, network and application services that are hosted on the internet instead of on local physical devices.
2. Cloud Network - A collection of servers or computers that store resources and data in remote data centers that can be accessed via internet. Cloud networks use remote servers.

# COMMUNICATION
1. Communication over a network happens when a data move from one point to another.
2. Data Packets - A basic union of informafion that travels from one device to another within a network.
Data packet has HEADER which contains - IP address/MAC address/Protocol Number. 
MAC address - Media Access Control address
Data Packet also has BODY(message) and FOOTER.
3. Network performance is measured with bandwidth.
4. Bandwidth is the amount of data a device receives every second.
5. Speed is the rate at which data packets are received or downloaded.
Security personnel is always interested in network bandwidth and speed because irregularity is indication of attack.
6. Packet Sniffing is the practice of capturing and inspecting data packets across network.
