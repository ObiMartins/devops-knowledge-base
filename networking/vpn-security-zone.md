# VPN

1. Virtual Private Network(VPN) - A network security service that changes your public address and hides your virtual location so that you can keep your data private when you are using a public network like internet. It uses data encryption.
2. Encapsulation - A process perform by a VPN service that protect your data by wrapping your sensitive data in other packets.
3. Security Zone - A segment of a network that protects the internal network from the internet. It is part of network service called network segmentation.
4. Network Segmentation - A security technique that divides the networks into segments.
5. Two types of network zones: 
- Uncontrolled Zone - Any network outside the organization's control. like internet.
- Controlled zones - A subnet that protects the internal network from uncontrolled zone.
6. Areas in the Controlled Zone.
- Demilitarized Zone(DMZ)
- Internal network
- Restricted zone
