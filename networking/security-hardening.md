# Security Hardening

# Security Hardening is the process strengthening a system to reduce it's vulnerabilities and attack surface.

1. Attack Surface - All the potential vulnerabilities that a threat actor could exploit.
2. Security hardening is conducted on systems or devices that could be compromised.
- Hardwares
- Operating systems
- Applications
- Computer networks
- Databases
- other physical devices and environments

3. Hardening Procedures and Strategies:
- Software update(patches)
- Device configuration changes
- Removing od disabling unwanted applications 
- Disabling unused ports.
- Reducing access permission across networks
- Conducting regular penetration test.

4. Penetration Test - A simulation of attack that helps indentify vulnerabilities in systems, networks, websites, applications and processes.
5. Patch Update - A software or operating system update that addresses security vulnerabilities in a program or product.
6. Basedline Configuration(baseline image) - A documented set of specifications within a system that is used as basis for future builds, releases or updates.
