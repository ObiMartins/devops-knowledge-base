# Useful Terraform Commands
Command	                      Description

# terraform init -------------Initializes a new or existing Terraform working directory. Downloads    the necessary provider plugins.
# terraform plan -------------Generates an execution plan. It shows you what resources will be created, changed, or destroyed without actually doing it.
# terraform apply ------------Applies the changes required to reach the desired state of the configuration.
# terraform destroy	----------Destroys all infrastructure objects managed by the current Terraform configuration.
# terraform validate ---------Checks if the configuration files in a directory are syntactically valid and internally consistent.
# terraform fmt	--------------Automatically updates your configuration files to a canonical format and style (cleans up code indentation and spacing).
